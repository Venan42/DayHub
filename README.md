# DayHub

Projeto abrangente criado para concentrar funcionalidades úteis para o meu estilo de vida. Ele tem o objetivo de praticar tecnologias que não tenho tantas afinidades, como Flutter, LiteLLM, Docker, etc.

## Ideia

Uma plataforma pessoal para organizar três áreas do dia a dia:

- **Finanças** — controle de transações e categorias.
- **Mídia** — armazenamento e visualização de arquivos.
- **Tarefas** — checklist simples de afazeres.

## Stack (planejada)

- **Backend:** Python, Litestar, Beanie/MongoDB.
- **Frontend:** Flutter.
- **Autenticação:** JWT.
